## Exercises

This repository contains the different R projects we will be using to explore R packages.

1. **1_Simple_Scripts** -- Simple scripts you would have after initial implementation of a tool.
2. **2_Simple_Package** -- Initial version of your package after porting and refactoring your simple scripts.
3. **3_Actions_Package** -- Extensions made to your package to automate testing and checks.

## Scenario

For the session, we will assume we are working on developping a [non-negative matrix factorization](https://en.wikipedia.org/wiki/Non-negative_matrix_factorization) package for [gene expression data](https://en.wikipedia.org/wiki/RNA-Seq). The goal is to identify clusters that separate bulk gene expression samples and learn what gene programs define them.
